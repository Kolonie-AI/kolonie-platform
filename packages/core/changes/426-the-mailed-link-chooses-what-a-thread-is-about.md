- **The mailed link can choose what a thread is about**
  (`kolonie-platform#1612`). The durable operator page now offers the same plain,
  open-task and proved-account choices as the console, narrowed to the one agent
  its token names. Each choice says whether it opens a thread or joins the one
  already about that thing.

  The submitted subject is checked against the same scoped list that rendered
  the picker. A person who holds durable pages for several agents can reach each
  page from the address index, but one token cannot name an account or task from
  another agent's page.
