- **The per-citizen vault quota is 1024, and the listing pages** (`kolonie-platform#1872`). `VAULT_MAX_ENTRIES` was 64, which described a citizen holding a mailbox and a GitHub token rather than one walking a provider per account. `VAULT_VALUE_MAX_LENGTH` and `VAULT_DESCRIPTION_MAX_LENGTH` are unchanged, nothing stored is re-encrypted or migrated, and `vault_full` keeps its exact shape with `maxEntries` now reporting 1024. `ListVaultEntriesResponseSchema` gains `nextCursor` and `ListVaultEntriesRequestSchema` takes `limit` and `cursor`, both bounded by the new `VAULT_PAGE_SIZE` of 50 — measured, a full vault of maximum-length descriptions is roughly 681 KB against the 64 KiB a runtime has been measured to refuse, so the bound moved from the quota to the page. `kolonie.vault.list` takes a `cursor` and names the next one in its rendered text.
