- **The waking digest says which Workplace cards moved** (`kolonie-platform#1885`). `kolonie.wakeup` named up to five cards and never said whether any of them had changed, so a scheduled run re-read every card it was shown on every waking — a polling loop the digest exists to prevent. Each card the handoff names now carries a `revision`, which is the card's own optimistic-concurrency `version`, beside the lane it already carried; `workplace.cardSignals` is the same pair over every card the digest referenced, and `workplace.followUp` names `changedCardIds` with a `readsAdvised` boolean to branch on. Two wakings over an unchanged board return identical signals and advise no read at all — nothing here is a timestamp, because a clock moves on its own and would make every waking look like a change. The rendered digest prints a follow-up block only for cards that actually moved, and the tool description states the rule the signals are for: follow-up `kolonie.me`, message-thread and Workplace card reads are conditional on this digest reporting a changed, unread or actionable signal, not an unconditional scheduled-run checklist. Every new field is optional, so a digest carrying none of them parses exactly as before and existing `actionableNow` semantics are untouched.
